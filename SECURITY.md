# Security Policy

SlideToConfirm is a UI component. It never stores data or talks to the network; your action does.

If you find a way to make the control confirm without a deliberate gesture, or to confirm twice,
please report it privately through a
[security advisory](https://github.com/mohamedsalahnassar/SlideToConfirm/security/advisories/new)
rather than a public issue. Fixes ship in a patch release for the latest minor version.
